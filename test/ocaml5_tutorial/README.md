# OCaml 5 tutorial case studies

Implementations from the [OCaml 5 tutorial](https://github.com/ocaml-multicore/ocaml5-tutorial),
with Caravan contracts and proofs in companion files.

- [Blocking stack](blocking_stack/): a polymorphic stack protected by a mutex and a condition variable.
